# Beejoyi (বিজয়ী): redesign prototype

The contest platform for students in Bangladesh, from preschool to university. This repo holds the redesigned website, built page by page with Next.js, Tailwind CSS and Base UI.

- **What's done and what's next:** [docs/ROADMAP.md](docs/ROADMAP.md)
- **Design reasoning per page:** [docs/](docs/)

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000. The UI is Bangla by default; switch to English from the header.

All contests, numbers, profiles and payments are **sample data** for the prototype.
